One-line: the two text roles inside a Card — 18/24 bold title, 14/21 muted copy.

```jsx
<CardTitle>Hear back from Captain</CardTitle>
<CardCopy>Enable updates for completed uploads and work that needs your attention.</CardCopy>
```

Notes: card titles are sans, not Fraunces. Fraunces is reserved for screen titles and display numerals.
